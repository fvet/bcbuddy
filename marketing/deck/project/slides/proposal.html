Getting started takes three steps. Install BC Buddy from the Chrome Web Store; the web client improvements work at once, with nothing to set up. Then give each environment its own colour on the settings page, so production never looks like a test environment. Finally, export the settings to one file and share its address with your team: everyone gets the same colours and web client settings, including later changes. BC Buddy is free, installs nothing in Business Central, and one switch turns it off.
