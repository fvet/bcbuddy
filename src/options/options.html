Shared configuration

Host a JSON file on a public HTTPS URL (e.g. a raw GitHub link) so everyone in the company uses the same markers.

Only use a URL you control (for example your team's repository). The file can define rules that mark any site.

Import / export

Import

From a file. Rules you already have are overwritten, new ones are added, and rules that are not in the file are left alone. This does not touch the shared configuration.

Export

Exports your own rules only, in the format this extension also reads.

About

BC Buddy gives every Business Central environment its own colour: ribbon, frame, banner, tab title and favicon. One glance tells you whether you are in production, a sandbox or a demo, so you never change the wrong environment by accident.
