JUSTIFICATIE PER MACHTIGING (Engelse tekst voor het formulier "Privacy practices";
bron: PRIVACY.md en DEVELOPMENT.md, sectie Permissions)
- storage: keeps the user's settings and rules on their own computer.
- alarms: checks the optional shared configuration file once a day.
- scripting: shows the area selection and the drawing editor of Help & feedback
  on the Business Central page, only while the user uses them, after they start it
  from the side panel.
- sidePanel: shows the keyboard shortcuts for the current page and the Help &
  feedback report in the browser's side panel. Needs Chrome 116 or newer.
- downloads and downloads.open (optional, asked on the first click on Email):
  save the report as an email file and open it in the user's email app. Only that
  one file is touched; other downloads are never read or changed.
- host permission <all_urls>: rules may match any URL, because Business Central
  on-premises runs on the customer's own host name, and the shared configuration
  file can be hosted anywhere. Used to mark pages that match a rule, to apply the
  web client improvements on Business Central pages, and to take the screenshots
  the user adds in Help & feedback.
- Remote code: none. All code is in the package.
- Single purpose: make Microsoft Dynamics 365 Business Central easier to work in
  (web client improvements, environment colours, in-page problem reports).
- Data use: nothing is collected or sent. A problem report only goes to the user's
  own email app or clipboard. Privacy policy: https://fvet.github.io/bcbuddy/privacy/
