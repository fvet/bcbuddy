--------------------------------------------------------------------------
1. EEN DOEL / SINGLE PURPOSE
--------------------------------------------------------------------------
BC Buddy visually marks Business Central environments in the browser - the
top bar, a frame, a banner, the tab title and the tab icon - so the user can
tell one environment from another and avoid acting in the wrong one.


--------------------------------------------------------------------------
2. VERANTWOORDING "storage"
--------------------------------------------------------------------------
Stores the user's own configuration: the rules that decide which environment
gets which colour, the layouts that decide how a marking looks, and the
optional URL of a shared configuration file. All of it is written to
chrome.storage.local and never leaves the device. Without this permission the
extension would forget the user's settings on every restart.


--------------------------------------------------------------------------
3. VERANTWOORDING "alarms"
--------------------------------------------------------------------------
Schedules a single daily check of the shared configuration file that the user
optionally points at, so that a change made centrally reaches everyone in the
team without manual action. The alarm is only created when the user has
configured such a URL, and it triggers nothing else.


--------------------------------------------------------------------------
4. VERANTWOORDING HOSTRECHTEN (<all_urls>)
--------------------------------------------------------------------------
The extension must be able to match and mark any URL for two reasons.

First, Business Central on-premises runs on the customer's own host name,
which is different for every installation and cannot be known in advance, so
no fixed host pattern would cover it. Business Central online is only one of
the addresses users need marked.

Second, the optional shared configuration file is hosted by the user on a
domain of their choosing, so the extension cannot predict that host either.

The access is used solely to draw the extension's own markings on pages that
match a rule the user defined. The content script reads the page URL and
locates the client's top bar in the DOM in order to recolour it. Nothing that
is read is stored, logged, or transmitted anywhere, and no page content is
sent off the device.


--------------------------------------------------------------------------
5. EXTERNE CODE / REMOTE CODE
--------------------------------------------------------------------------
Kies: "Nee, ik gebruik geen externe code."

Verschijnt er toch een tekstvak, plak dan dit:

All executable code ships inside the package. The extension loads no scripts,
stylesheets or WebAssembly from any remote source and uses no eval() or
equivalent. The only thing fetched at runtime is the shared configuration
file, which is parsed as JSON data and never executed.


--------------------------------------------------------------------------
6. GEGEVENSGEBRUIK / DATA USAGE
--------------------------------------------------------------------------
Vink GEEN van de gegevenscategorieen aan. De extensie verzamelt niets:
geen persoonsgegevens, geen locatie, geen surfgeschiedenis, geen
gebruikersactiviteit, geen website-inhoud. Er wordt niets van het toestel
verstuurd.

Vink daarna de drie verklaringen onderaan aan:
  - gegevens worden niet verkocht of doorgegeven aan derden
  - gegevens worden niet gebruikt buiten het aangegeven doel
  - gegevens worden niet gebruikt voor kredietwaardigheid of leningen

Dit is de certificering die de foutmelding vraagt; zonder deze drie vinkjes
blijft publiceren geblokkeerd.
